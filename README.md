# 學術佳句庫 Academic Phrasebank

依論文章節分類的英文學術句型庫。讀論文時看到好用的句子，就把它抽象成「句型模板 + 原創例句 + 中文說明」收進來，寫 SCI 論文時直接套用。

🔗 網站：https://yenchen-h.github.io/academic-phrasebank/

## 專案特色

- **9 個論文章節 + 2 個寫作工具**：摘要、研究背景、文獻探討、研究缺口、研究目的與貢獻、研究方法、結果呈現、討論與限制、結論，以及語氣保留與轉折、統計分析與報告，共 92 個句型
- **段落結構**：每章附上歸納自 SCI 論文的寫作步驟（Move），並連到對應句型
- **句型模板**：`[[ ]]` 內為可替換部分，網頁自動上色，一鍵複製
- **標籤篩選**：每頁依卡片標籤自動產生篩選按鈕
- **在網頁上新增自訂句型**：每頁都有「＋ 新增我的句型」，存在瀏覽器中，可在首頁匯出／匯入 JSON；匯出檔可交給 AI 依 AGENTS.md 任務 E 正式收錄
- **AI 可持續擴充**：`AGENTS.md` / `CLAUDE.md` 定義了資料夾結構、命名、卡片格式、英文寫作規則與新增流程

## 如何請 AI 繼續擴充

```
請先讀 AGENTS.md。幫我在「研究缺口」新增一個句型：指出既有資料集規模太小。
```

```
請先讀 AGENTS.md。幫我新增一個「結論 Conclusion」章節頁。
```
